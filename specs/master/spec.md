# 首页（工作台）功能规范

## 版本信息

**版本**: 1.0.0 | **创建日期**: 2026-03-24 | **最后更新**: 2026-03-24

---

## 1. 功能概述

首页（工作台）是银行信贷管理系统的用户主界面，提供待办任务概览和公告展示功能，帮助用户快速了解待处理工作和系统通知。

---

## 2. 用户场景

### 2.1 主要用户

- 系统管理员
- 信贷审批人员
- 贷后管理人员
- 其他业务操作人员

### 2.2 使用场景

| 场景 | 描述 |
|------|------|
| 登录后的首页 | 用户登录后查看待办任务和公告 |
| 日常操作 | 用户通过首页导航进入各功能模块 |
| 获取通知 | 用户查看系统公告了解重要信息 |

---

## 3. 功能需求

### 3.1 待办任务展示

| ID | 需求 | 优先级 |
|----|------|--------|
| FR-001 | 显示待审批申请数量 | 高 |
| FR-002 | 显示待审批数量 | 高 |
| FR-003 | 显示待签署合同数量 | 高 |
| FR-004 | 显示待放款数量 | 高 |
| FR-005 | 显示待处理还款数量 | 高 |
| FR-006 | 显示预警数量 | 中 |
| FR-007 | 显示贷后任务数量 | 中 |
| FR-008 | 显示其他任务数量 | 低 |

### 3.2 公告栏功能

| ID | 需求 | 优先级 |
|----|------|--------|
| FR-010 | 显示最新 5 条公告 | 高 |
| FR-011 | 公告显示标题和发布日期 | 高 |
| FR-012 | 无公告时显示提示 | 中 |

### 3.3 导航功能

| ID | 需求 | 优先级 |
|----|------|--------|
| FR-020 | 左侧菜单导航至各功能模块 | 高 |
| FR-021 | 当前菜单项高亮显示 | 中 |
| FR-022 | 顶部显示系统名称和用户信息 | 高 |
| FR-023 | 退出登录功能 | 高 |

### 3.4 数据接口

| ID | 需求 | 优先级 |
|----|------|--------|
| API-001 | GET /api/dashboard/todo - 获取待办统计 | 高 |
| API-002 | GET /api/announcements - 获取公告列表 | 高 |

---

## 4. 非功能需求

### 4.1 性能要求

- 首页加载时间不超过 3 秒
- 待办数据接口响应时间不超过 1 秒

### 4.2 可用性

- 界面简洁直观，无需培训即可使用
- 支持键盘导航

### 4.3 兼容性

- 支持主流浏览器（Chrome, Firefox, Edge）
- 支持 1920x1080 及以上分辨率

---

## 5. 数据结构

### 5.1 待办统计响应格式

```json
{
  "code": 200,
  "data": {
    "application": 12,
    "approval": 5,
    "contract": 3,
    "loan": 8,
    "repayment": 20,
    "warning": 3,
    "postloan": 7,
    "other": 15
  }
}
```

### 5.2 公告列表响应格式

```json
{
  "code": 200,
  "data": [
    {
      "title": "公告标题",
      "createdAt": "2026-03-24"
    }
  ]
}
```

## 6. 假设与依赖

### 6.1 假设

- 用户已通过身份认证
- 后端 API 服务正常运行
- 数据库中存在公告数据表

### 6.2 依赖

- 公告管理模块
- 用户认证模块
- 各业务模块的待办统计接口
